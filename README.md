# السيد الخفي 33 — 3D Prototype v4

هذا الإصدار هو نموذج 3D فعلي يعمل عبر Three.js WebGL، ولا يعتمد على الكرة القديمة أو Canvas كمشهد رئيسي.

## التشغيل

افتح `index.html` عبر خادم static بسيط أو انشر المشروع على GitHub Pages / Cloudflare Pages.

## ملاحظة

النسخة الحالية Pilot للمرحلة الأولى فقط: غرفة قيادة ثلاثية الأبعاد + هولوغرام أرض + شاشات + إضاءة + كاميرا متحركة + قرارات تغير المشهد.
